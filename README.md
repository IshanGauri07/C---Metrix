C-Metrix is a collection of C programming practice programs designed for beginners and students to improve their problem-solving and programming skills.
The project contains multiple C language programs organized by pages/topics, covering fundamental programming concepts and logic building.

It is useful for:

C programming practice
Academic lab work
Beginner coding exercises
Understanding programming logic
Learning syntax and problem-solving techniques
🚀 Features
Multiple C programs in one project
Beginner-friendly source code
Organized folder structure
Easy to compile and run
Useful for students and coding learners
🛠️ Technologies Used
Language: C
Editor: VS Code
Compiler: GCC / MinGW
📂 Project Structure
C-Metrix/
├── page - 32/
├── page - 33/
├── page - 40/
└── .vscode/

Each folder contains different C programs (.c files) for learning and practice.

▶️ How to Run
Install GCC Compiler
Open project in VS Code
Compile program:
gcc filename.c -o output
Run program:
./output
💡 Purpose of Project

The main purpose of this project is to help students practice C programming concepts through hands-on coding examples and improve their logical thinking.
